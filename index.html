Run game is completely broken when the line gets disrupted — 0 for 4 (0%). Pass game actually held at 50% in those same situations. The QB can improvise; a designed run play can't. Worth calling an RPO or QB keeper when you see pressure at the snap.
🚨
4 turnovers is the story of this game. All 3 INTs came from the QB — leaning back, throwing off rhythm, or forcing it into coverage late. The fumble came from a bad snap + line breakdown combo on their own 9-yard line (Play 19). Ball security is the priority.
📈
Plays 70–75: 6 straight successful pass plays. Something clicked — formation, protection, route combos. That's the tape to rewind all the way and break down. If you can replicate that run in the first half, this game looks very different.
